# Image assets (placeholders)

All images here are **dummy placeholders** (royalty-free Unsplash photos) used during the UI stage.
Replace them with the client's real photos by overwriting the file with the same name
(or update the path in `index.js`). Recommended: JPG/WebP, ~1200px wide, under 250 KB.

| Folder        | Used for                              |
| ------------- | ------------------------------------- |
| `products/`   | Product cards (laptop, desktop, keyboard, printer) |
| `categories/` | Category tiles                        |
| `offers/`     | Offer cards                           |
| `services/`   | Service cards                         |
| `about/`      | About page (store, team)              |
| `banners/`    | CTA banner and other backgrounds      |
